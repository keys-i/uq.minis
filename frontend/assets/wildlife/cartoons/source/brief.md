# Whole cartoon residents

Generated with the built-in image-generation tool on 23 October 2026
The original `frontend/assets/images/wildlife.webp` and `poses.webp` sheets supplied the visual references

The brief requested rounded, friendly whole animals matching those references, with attached anatomy, transparent backgrounds, distinct silhouettes and one awake plus one resting pose
Species-specific anatomy stays recognisable without joining separately painted body parts

`residents.png` uses eight columns and four rows, with consecutive awake/rest pairs for mink, solenodon, potoroo, melomys, skink, paddlefish, crayfish, dog, orangutan, leopard, lynx, gorilla, bonobo, lemur, aye and tamarin

`neighbours.png` uses five columns and four rows
Rows one and two contain awake and resting macaque, tahr, dolphin, bustard and florican
Rows three and four contain awake and resting vulture, gharial, Indian pangolin, parakeet and eagle

`tools/scripts/atlas.py` isolates each whole silhouette and produces the WebP atlases and portraits in the parent directory
These PNG files remain editable production sources
