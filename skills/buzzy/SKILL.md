# Buzzy

Run Python commands from `backend/`
Open Buzzy in the browser for the colour calendar and subscription choices
Use `mini buzzy calendar -o out/buzzy/semester.ics` for a CLI calendar export or `mini buzzy show` for the shared private plan

Select actual enrolled courses in Scrappy first, then add or import reviewed assessments in Planny
Follow clubs in Clubby or save individual society events to include them
Official deadlines and personal targets remain separate; cancelled society events do not appear
Feed refresh failure retains saved events and the last complete snapshot

The calendar shares the existing private plan, revision checks and source validation
Local subscriptions require the backend to keep running; Google and Outlook need an independently hosted protected feed
Do not promise that opening an external university login establishes a minis identity
